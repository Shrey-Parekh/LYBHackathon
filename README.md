# control-tower-web

Web app for the Order-to-Delivery Control Tower, Problem Statement 3 of the LYB Mumbai Hackathon 2026 (Round 2). It serves three roles: logistics coordinator, transporter or driver (phone layout), and customer.

All data in this project is fictional. "Plant X" is the fictional company from the hackathon brief.

## Status

Design and planning only. No application code has been written yet.
